# 🌍 Gewerber Community Guide

Welcome to the **Gewerber Community**!
This document explains how our open‑core community works, how you can participate, and how we collaborate to build a friendly, helpful ecosystem for solo business owners in Germany.

Gewerber is more than a codebase — it's a community of developers, contributors, translators, designers, and users who believe that bureaucracy should be simple.

---

## 1️⃣ Community Values

Our community is built on:

- **Respect** — every contributor matters
- **Transparency** — open discussions, open decisions
- **Collaboration** — we build together
- **Inclusivity** — all backgrounds welcome
- **Quality** — thoughtful contributions over quick hacks
- **Guidance-first** — we help each other learn

We want Gewerber to be a place where people feel safe, supported, and empowered.

---

## 3️⃣ Community Structure

Maintainers oversee:

- Guiding contributors

### 🧑‍🤝‍🧑 Contributors

## 5️⃣ Contribution Workflow

1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Run tests
5. Submit a pull request
6. A maintainer reviews your PR
7. Changes are merged or feedback is provided

PR template:
**[PULL_REQUEST_TEMPLATE.md](PULL_REQUEST_TEMPLATE.md)**

---

## 6️⃣ Open‑Core Boundaries

Gewerber uses an **open‑core model**:

### ✔️ Open Source Modules
- Invoicing (no payments)
- Time tracking
- Basic accounting
- Guidance system
- UI Kit
- Core platform

### 🔒 Closed Modules (Not Open for Contribution)
- Banking
- Tax/ELSTER
- Employees
- Subscriptions
- AI assistant
- Multi‑currency invoicing
- Advanced accounting

Pull requests touching closed modules will be rejected.
