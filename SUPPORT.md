# 🆘 Gewerber Support

Need help with Gewerber? Here's how to get support.

---

## 🚑 Emergency / Security Issues

If you discover a security vulnerability, **do not** use public channels.

Report it privately:
**📧 Email:** `security@gewerber.de`

See **[SECURITY.md](SECURITY.md)** for full details.

---

## ❓ Community Support

For general questions, discussions, and community help:

- **GitHub Discussions** — [gewerber-app/discussions](https://github.com/Gewerber/gewerber-app/discussions)
- **Community Guide** — see [COMMUNITY.md](COMMUNITY.md) in the .github repository

## 🐞 Bug Reports

If you found a bug, please report it using our:

## ✨ Feature Requests

Have an idea for an open-source feature? Submit it using:

**[Feature Request Template](ISSUE_TEMPLATE/feature_request.md)**

> **Note:** Feature requests for closed modules (banking, tax/ELSTER, employees, subscriptions, AI assistant) are not accepted in the open-source repositories.
