# Gewerber — Business. Simplified. 🌿

> **Business. Simplified.**
>
> Gewerber is an open-source, Dart-based platform built for solo business owners (*Einzelunternehmer*, *Kleingewerbe*) in Germany. We believe running a business should be clear, calm, and confident — not drowned in bureaucracy.

Gewerber replaces spreadsheet chaos and paper clutter with a unified, modern toolset. The open-source core covers the essentials: invoicing, time tracking, basic accounting, and guided workflows — all in one language, one ecosystem, one philosophy.

## ✦ What's Open Source 🎯

Gewerber Core is free, MIT-licensed, and built to be transparent and extensible:

| Feature | What you get |
|---|---|
| 💰 **Invoicing** | Professional invoices, PDF export, Kleinunternehmer §19 & VAT logic |
| ⏱ **Time Tracking** | Projects, tasks, timer, rounding, reports |
| 📊 **Basic Accounting** | Income & expenses, receipts, P&L, CSV export |
| 📖 **Guidance** | Tooltips, checklists, progress tracking — built-in help |
| 🎨 **UI Kit** | Shared Flutter components, forms, tables, cards |

All under the [MIT License](LICENSE.md) — completely free, no hidden paywalls.
